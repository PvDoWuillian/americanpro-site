Dúvidas frequentes

Perguntas Frequentes

Vocês criam bots do zero ou usam bases prontas?
Desenvolvemos 100% do zero em Node.js (discord.js) ou Python (disnake/nextcord). Não usamos "bases prontas" genéricas. O código é seu, limpo, comentado e versionado no GitHub privado (se desejar).
A hospedagem realmente fica online 24h? E se cair?
Sim. Nossa infraestrutura tem 99,9% de SLA. Temos monitoramento ativo (Uptime Kuma + Prometheus) que alerta a equipe automaticamente se o container parar. O reinício automático está configurado por padrão no painel.
Como funciona o suporte técnico?
Atendimento humanizado via Discord (ticket privado), todos os dias das 13h às 00h (BRT). Planos Ouro e Platina têm prioridade na fila e acesso direto à equipe sênior. Fora do horário, o painel permite reiniciar/ver logs sozinho.
Posso upar/downgradar o plano depois?
Pode. Upgrade é imediato (paga diferença pro-rata). Downgrade entra no próximo ciclo de faturamento. Seus dados (banco, arquivos) são preservados sempre.
Vocês fazem a manutenção do bot depois de pronto?
Sim. Oferecemos pacotes de manutenção mensal (correção de bugs da API do Discord, pequenas features, atualização de dependências). Para clientes de hospedagem, correções críticas de compatibilidade são gratuitas.
Quais linguagens/frameworks vocês suportam na hospedagem?
Node.js (todas versões LTS/Current), Python 3.10+, Java 17/21, Go, Rust, PHP 8.2+, .NET 8. O painel Pterodactyl usa Docker: se roda em container Linux, roda na gente.
